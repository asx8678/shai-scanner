### How to Use These Templates

1. **Find the right template** - Use the table above or browse the category files
2. **Copy the template** - Select the template content from the appropriate file
3. **Customize** - Replace all `[placeholders]` with actual information
4. **Review** - Ensure all placeholders are filled and tone is appropriate
5. **Send** - Use the customized template in your response

### Template Structure

Each template includes:
- **Template Name** - Unique identifier for the template
- **Description** - What the template is for
- **When to use** - Situations where this template is appropriate
- **Template Content** - The actual template with placeholders
- **Example Usage** - A filled-in example of the template
- **Related Documentation** - Links to relevant documentation

### Customization Tips

- Remove brackets `[ ]` from placeholders after filling them in
- Adjust formality based on customer relationship
- Add/remove sections based on relevance
- Include screenshots when helpful
- Link to specific docs rather than general pages

### Quality Checklist

Before sending any response:
- [ ] All placeholders filled correctly
- [ ] No sensitive information exposed
- [ ] Documentation links are valid
- [ ] Tone is appropriate and professional
- [ ] Action items are clear and specific
- [ ] Timeline is realistic
- [ ] Contact information is correct
